## Known Limitations

- Live runs so far: none on this version. Every command is `draft` until its behavior matrix passes on the real application.
- Only Xpedition 2604 on Windows x64 is supported; COM exists only on Windows.
- One Designer and one Layout at a time: COM reaches only one instance of each program.
- Xpedition does not report unsaved changes or a change counter through COM, so `dirty` and `revision` come from the tool's own writes, and `dirty` is `null` for a document the tool did not open or save; edits a person makes in the application are not seen (knowledge `xpedition-external-edits-not-tracked`).
- After sheet operations Designer reads its design correctly only once the project is saved, closed and opened again (knowledge `designer-reopen-after-sheet-changes`); `schematic create` reads back without reopening, which worked in the live run on Xpedition Enterprise 2604.
- Bottom-side placement, window screenshots and refreshing a board's cells are not offered.
- `doc save` takes one to two minutes: after saving it closes and opens the document again, because Designer's database server writes the project files only when the project closes, and it reads the saved changes back from the reopened document. It reports the save `saved` only when it saw the files in the document's folder change.
