# Route a board

Rules come before copper: set the widths, spacing, clearances and the via, then route, pour and open the soldermask, then check. Before each command, read the knowledge entries `xpedition-cli knowledge list --applies-to <command>` returns.

1. Rules. `constraint get --output <rules.json>` writes the board's rules. Keep in the file only what the design asks to create or change: net classes for the impedance lines, the power nets and the rest, their widths and differential spacing per layer, the differential pairs, and the clearance rules with the class pairs that use them. Impedance widths and spacing come from the fabricator's impedance table. Then `constraint import --file <rules.json>`. The file format is in [rules-file.md](rules-file.md).
2. Via. `padstack list --type via` shows the vias of the central library; `padstack create --drill <mm> --pad <mm>` adds the one the design asks for.
3. Route. `router run --net-classes <classes>` routes the classes named, critical classes first, each run in its own call; `--passes` chooses the route passes. The router places the via each net class is assigned in Constraint Manager, so follow it with `via update --net-classes <classes> --padstack <via>`. Routes the router leaves or that must follow a given path go in a routing plan for `trace create --file <plan.json>`; its format is in [routing-plan.md](routing-plan.md). `trace delete` and `via delete` take back a routing attempt.
4. Copper. `plane create --net GND --layer <n>` pours a plane; on flex, `--hatch orthogonal` or `diagonal` with `--hatch-width` and `--hatch-distance` keeps it bendable. `via create --net GND --pitch <mm>` stitches the planes of two layers together. `plane delete` takes a plane back.
5. Bare copper. `solder-mask create --x1 --y1 --x2 --y2` opens the soldermask over a rectangle, on `--side bottom` when asked; on a flex board, `--cover-layer` opens the coverlay instead. The preview names the nets whose copper it bares.
6. Check. `pcb check` runs DRC and lists the hazards; `pcb get` reports how many nets are still open. `pcb render --output <file.png>` draws the board for the person; never check a result by looking at the picture.
